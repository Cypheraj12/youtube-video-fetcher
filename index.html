🚀 Backend Architecture & Integration Specs

⚡

Async Background Cron

Runs scheduled periodic workers querying the YouTube Search endpoint, validating new uploads against existing video IDs to prevent duplicates.

🔑

API Key Auto-Rotation

Gracefully catches quota exhaustion errors (HTTP 403 / quotaExceeded) and transparently switches to fallback API credentials without service outage.

🍃

MongoDB Compound Index

Stores records indexed on published_at: -1 and text indexed on title and description for sub-millisecond retrieval latency.
